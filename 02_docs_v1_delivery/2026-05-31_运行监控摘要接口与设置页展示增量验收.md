# 运行监控摘要接口与设置页展示增量验收

## 本轮目标

在已有健康检查、就绪检查和运行配置摘要基础上，补齐管理台可查看的运行监控指标，为交付清单中的“监控指标可查看”提供最小可用能力。

## 后端变更

- 新增 `GET /settings/monitoring`。
- 接口返回当前后端进程的运行监控快照：
  - 进程状态。
  - 指标采集时间。
  - 启动至今秒数。
  - goroutine 数量。
  - 堆内存已分配 MB。
  - 堆内存向系统申请 MB。
  - 堆对象数量。
  - 累计 GC 次数。
  - 距离最近一次 GC 的秒数。
- 接口不返回数据库 DSN、Redis 地址、MinIO 密钥、模型 API Key、JWT 密钥或 License 公钥原文。
- 增加监控快照构造和接口响应单元测试。

## 前端变更

- 管理台“设置”页新增“运行监控摘要”区域。
- 支持点击“刷新”读取 `/settings/monitoring`。
- 中文摘要展示进程状态、运行时长、goroutine、堆内存、堆对象、GC 状态和检查时间。
- 不新增黑色 JSON 原文展示区。

## 验收步骤

1. 登录管理台。
2. 打开“设置”页面。
3. 点击“运行监控摘要”区域的“刷新”。
4. 确认页面展示进程状态、运行时长、goroutine、堆内存和 GC 状态。
5. 确认页面不展示任何密钥、DSN 或原始连接串。

## 验证命令

- 前端语法检查：`D:\Node.js\node.exe --check 02_frontend\assets\app.js`
- 后端测试：在 `01_backend` 目录执行 `go test ./...`
- 差异检查：`git diff --check`

## 注意事项

- 本轮不新增数据库迁移。
- 本轮不部署服务器，部署验证留到后续明确要求时执行。
- 本轮不读取服务器信息文件，不写入任何密钥。
