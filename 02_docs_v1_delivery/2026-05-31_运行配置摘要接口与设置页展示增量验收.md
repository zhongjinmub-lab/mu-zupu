# 2026-05-31 运行配置摘要接口与设置页展示增量验收

## 本轮目标

在已完成限流策略动态展示基础上，继续补齐部署前可见性：让管理台能只读查看后端运行配置摘要、Worker 参数和模型接入状态。

本轮只做本地主线开发，不执行服务器部署验证，不读取服务器信息文件。

## 后端变更

- 新增接口：`GET /api/v1/settings/runtime`。
- 接口挂在登录用户路由下，不强制租户上下文，因为返回的是全局运行配置摘要。
- 返回内容包括：
  - 运行环境。
  - 上传文件上限。
  - 对象存储模式和公开访问是否配置。
  - Embedding Provider、模型名、外部连接是否配置。
  - Generation Provider、模型名、外部连接是否配置。
  - 文档 Worker 轮询间隔和批量大小。
  - Webhook Worker 轮询间隔、批量大小、最大重试次数和基础重试间隔。
- 接口不返回数据库 DSN、Redis 地址、MinIO 密钥、模型 API Key、JWT 密钥或其他敏感原文。

## 前端变更

- 设置页新增“运行配置摘要”面板。
- 面板展示中文摘要卡片：
  - 运行环境与上传上限。
  - 对象存储模式。
  - Embedding 接入状态。
  - 生成模型接入状态。
  - 文档 Worker 参数。
  - Webhook Worker 参数。
  - Webhook 重试策略。
- 全局刷新、切换租户和设置页手动刷新都会更新该摘要。
- 展示继续使用中文摘要，不展示黑色 JSON 原文区域。
