# 2026-05-31 Webhook 投递摘要筛选口径统一增量验收

## 本轮目标

在 Webhook 投递记录已支持筛选、CSV 导出和时间范围过滤之后，把“投递状态摘要”同步改为使用同一套筛选条件，避免摘要与列表统计口径不一致。

本轮只做本地主线开发，不执行服务器部署验证，不读取服务器信息文件。

## 后端变更

- `GET /api/v1/webhook-deliveries/summary` 支持复用投递记录筛选参数：
  - `endpoint_id`
  - `event_type`
  - `status`
  - `from`
  - `to`
- 摘要接口仍固定按当前租户隔离，不接受客户端覆盖 `tenant_id`。
- `from`、`to` 的解析和校验规则与投递记录列表、CSV 导出保持一致。

## 前端变更

- 投递状态摘要刷新时会先读取当前筛选表单。
- 摘要、投递记录列表、CSV 导出统一使用 `webhookDeliveryFilters`。
- 点击摘要区“刷新”时，也会按当前 Webhook、事件、状态、开始日期、结束日期筛选统计。
