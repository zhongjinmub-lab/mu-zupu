## 管理台

- 智能体列表新增“归档”操作；
- 归档前弹出浏览器确认，避免误操作；
- 确认后调用 `DELETE /api/v1/agents/:agent_id`；
- 归档成功后刷新 Agent 列表，并清空/刷新当前绑定关系、会话列表和消息列表。

- 已归档 Agent 不再出现在当前租户 Agent 列表中；
- 本增量不新增数据库结构，不新增后端接口。
