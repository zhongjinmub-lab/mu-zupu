# 数据分析摘要 CSV 导出增量验收

## 本轮目标

在已有统计 API、数据分析面板和智能体族谱统计基础上，补齐分析摘要 CSV 导出能力，方便交付验收、运营周报和离线留档。

## 后端变更

- 新增 `GET /analytics/summary/export`。
- 接口固定按当前租户上下文导出，不接受客户端覆盖 `tenant_id`。
- CSV 覆盖以下统计分区：
  - 资源结构。
  - 经营指标。
  - 订单、支付、授权状态分布。
  - 智能体族谱结构和关系类型分布。
  - 近 7 天用量趋势。
  - 运营风险。
  - 最近操作。
- CSV 字段为 `section`、`name`、`status`、`quantity`、`unit`、`occurred_at`、`generated_at`。

## 前端变更

- 管理台“数据分析面板”新增“导出 CSV”按钮。
- 点击后直接下载 `analytics-summary-*.csv` 文件。
- 导出失败时显示中文错误摘要。
- 不新增黑色 JSON 原文展示区。

## 验收步骤

1. 登录管理台并选择租户。
2. 打开“数据分析面板”。
3. 点击“刷新分析”，确认页面能正常展示统计摘要。
4. 点击“导出 CSV”。
5. 确认浏览器下载 `analytics-summary-*.csv` 文件。
6. 打开 CSV，确认包含资源、经营、族谱、用量趋势、风险和最近操作等 `section`。
