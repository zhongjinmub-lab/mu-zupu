# 智能体族谱 CSV 导出增量验收

## 本轮目标

在已有智能体族谱图谱展示和关系维护能力基础上，补齐 CSV 导出能力，方便交付验收、离线留档和排查关系数据。

## 后端变更

- 新增 `GET /agent-genealogy/export`。
- 导出当前租户未归档智能体节点和当前租户族谱关系。
- 返回 `text/csv; charset=utf-8` 文件。
- CSV 使用 `section` 字段区分节点行和关系行：
  - `node`：智能体节点。
  - `edge`：族谱关系。

## 前端变更

- 管理台“智能体族谱图谱”区域新增“导出 CSV”按钮。
- 点击后直接下载 CSV 文件。
- 导出失败时显示中文错误提示。
- 不新增黑色 JSON 原文展示区。

## 验收步骤

1. 登录管理台并选择租户。
2. 打开“智能体”页面。
3. 确认“智能体族谱图谱”区域显示“导出 CSV”按钮。
4. 点击“导出 CSV”，确认浏览器下载 `agent-genealogy-*.csv` 文件。
5. 打开 CSV，确认包含 `section`、`id`、`name`、`code`、`parent_agent_id`、`child_agent_id`、`relation_type`、`created_at` 等字段。
6. 确认节点行 `section=node`，关系行 `section=edge`。

## 验证命令

- 后端测试：在 `01_backend` 目录执行 `go test ./...`
