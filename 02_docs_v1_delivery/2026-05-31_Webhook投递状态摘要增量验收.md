# 2026-05-31 Webhook 投递状态摘要增量验收

## 本轮目标

在已完成 Webhook 配置、投递记录筛选、手动重试和自动重试 Worker 的基础上，补齐管理台对 Webhook 投递总体状态的可见性。

本轮只做本地主线开发，不执行服务器部署验证，不读取服务器信息文件。

## 后端变更

- 新增接口：`GET /api/v1/webhook-deliveries/summary`。
- 接口固定按当前租户上下文统计，不接受客户端传入 `tenant_id`。
- 返回当前租户 Webhook 投递聚合数据：
  - `total`：总投递次数。
  - `success`：成功投递次数。
  - `failed`：失败投递次数。
  - `retry_scheduled`：已安排自动重试的失败记录数。
  - `retry_due`：已经到达重试时间、等待 Worker 认领的记录数。
  - `manual_review`：没有下一次自动重试时间、需要人工确认或手动重试的失败记录数。
  - `last_attempt_at`：最近一次投递尝试时间。

## 前端变更

- Webhook 页面新增“投递状态摘要”区。
- 摘要以中文卡片展示总投递、成功率、失败数、自动重试、人工处理和最近尝试时间。
- 以下操作会联动刷新摘要：
  - 全局刷新。
  - 切换租户。
  - 点击摘要刷新按钮。
  - 刷新投递记录。
  - Webhook 测试发送。
  - 删除 Webhook 配置。
  - 手动重试失败投递。
- 新增展示继续使用中文摘要，不展示黑色 JSON 原文区域。
