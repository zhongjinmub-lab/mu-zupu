# 2026-05-31 增量验收:微信支付 v3 渠道接入

## 背景

在可插拔支付渠道抽象层与支付宝渠道之上,新增微信支付 v3 Native 下单(扫码支付)作为第二个真实渠道,验证渠道抽象的可扩展性。mock 与支付宝渠道保持不变。

## 后端

- [x] 新增 `WechatProvider`,实现 `payment.Provider` 接口,通过 `BuildRegistry` 的 `wechat` 分支接入。
- [x] `CreatePrepay`:用商户 API 私钥按 `METHOD\nURL\ntimestamp\nnonce\nbody\n` 做 SHA256-RSA 签名,构造 `WECHATPAY2-SHA256-RSA2048` Authorization 头,调用 `POST /v3/pay/transactions/native`,返回二维码内容 `code_url`(`prepay.qr_content`)。
- [x] `VerifyNotify`:用平台证书公钥验签 `timestamp\nnonce\nbody\n`,再用 APIv3 密钥对资源体做 AES-256-GCM 解密,解析 `out_trade_no`/`transaction_id`/`trade_state`。
- [x] `trade_state` 映射:`SUCCESS` 记为已支付,`CLOSED`/`REVOKED`/`PAYERROR` 记为失败,中间态不更新支付单。
- [x] `NotifyResponse` 返回微信期望的 JSON 应答(成功 `{"code":"SUCCESS"}`,失败 `{"code":"FAIL"}` 并以非 200 触发重试)。
- [x] 新增 AES-256-GCM 解密辅助函数;RSA SHA256 签名/验签复用既有 `signRSA2`/`verifyRSA2`。
- [x] `config` 新增微信凭据配置:`WECHAT_APP_ID`、`WECHAT_MCH_ID`、`WECHAT_SERIAL_NO`、`WECHAT_API_V3_KEY`、`WECHAT_PRIVATE_KEY`、`WECHAT_PLATFORM_PUBLIC_KEY`、`WECHAT_GATEWAY`。
- [x] 复用既有公开端点 `POST /api/v1/payment-notify/wechat` 入账,租户隔离与 `order.paid` Webhook 逻辑不变。

## 前端

- [x] 订单支付渠道选择新增「微信支付」。
- [x] 对二维码渠道(`prepay.qr_content`)弹出可复制的支付链接,提示用户扫码完成支付。
