# 2026-05-31 Agent 多轮会话编排策略增量验收

## 增量范围

- 新增 `GET /api/v1/agents/conversation-orchestration-policy`，返回当前 Agent 多轮会话编排摘要。
- 摘要包含历史消息默认条数、最大条数、RAG 检索状态、SSE 流式状态、工具策略、额度指标、编排流程和安全说明。
- 管理台多轮会话区新增“会话编排策略”中文摘要。
- 多轮会话继续复用已落地的 `/agents/:agent_id/chat` 和 `/agents/:agent_id/chat/stream`。

## 验收点

- [x] 多轮会话校验当前租户、用户角色、Agent、会话和知识库归属。
- [x] 支持新建会话和 `conversation_id` 续聊。
- [x] 默认读取最近 20 条历史，最大允许 50 条。
- [x] 历史编排过滤 `tool` 角色消息，避免工具输出直接污染模型上下文。
- [x] 支持 RAG 引用、普通响应和 SSE 流式响应。
- [x] 每次成功会话写入 user/assistant 消息，记录 `agent_messages` 用量，并触发会话完成 Webhook。
- [x] 工具策略默认拒绝，危险工具不会被模型直接执行。

## 说明

本轮补齐可验收的会话编排摘要入口。真实工具 Runtime 尚未开放执行，当前闭环定义为“会话编排 + RAG + SSE + 用量 + 工具安全策略”。
