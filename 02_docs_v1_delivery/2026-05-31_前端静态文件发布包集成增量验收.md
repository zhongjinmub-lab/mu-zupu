# 2026-05-31 前端静态文件发布包集成增量验收

## 目标

将免构建静态管理台纳入后端生产发布包和升级/回滚脚本，避免后端升级后前端静态文件仍停留在旧版本。

## 变更

- `scripts/build_release.sh` 打包 `02_frontend` 到发布包 `frontend/`。
- `scripts/build_release.ps1` 打包 `02_frontend` 到发布包 `frontend/`。
- 发布包校验新增：
  - `frontend/index.html`
  - `frontend/assets/app.js`
  - `frontend/assets/app.css`
- `upgrade.sh` 快照和安装 `frontend/`。
- `rollback.sh` 回滚 `frontend/`。
- 生产部署文档新增 `/opt/mu-agent-saas/frontend` 目录说明和安装命令。
- release 脚本单测覆盖前端静态文件打包与升级/回滚脚本引用。
