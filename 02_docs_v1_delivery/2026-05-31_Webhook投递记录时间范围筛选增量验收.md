# 2026-05-31 Webhook 投递记录时间范围筛选增量验收

## 本轮目标

在已有 Webhook 投递记录筛选和 CSV 导出基础上，补齐按时间范围排查投递记录的能力，方便定位某一天或某一段时间内的失败投递。

本轮只做本地主线开发，不执行服务器部署验证，不读取服务器信息文件。

## 后端变更

- `GET /api/v1/webhook-deliveries` 新增时间范围筛选：
  - `from`：创建时间起点。
  - `to`：创建时间终点。
- `GET /api/v1/webhook-deliveries/export` 同步支持 `from` 和 `to`。
- `from`、`to` 支持 RFC3339/RFC3339Nano 和 `YYYY-MM-DD`。
- 同时传入 `from` 和 `to` 时，服务端会校验 `from` 不能晚于 `to`。
- 时间范围过滤固定作用于当前租户内的 `created_at`，不接受客户端覆盖 `tenant_id`。

## 前端变更

- Webhook 投递记录筛选栏新增“开始日期”和“结束日期”。
- 列表刷新、筛选提交、重置筛选、CSV 导出均复用同一套筛选状态。
- 结束日期按当天 `23:59:59.999` 处理，避免只查到当天零点。
