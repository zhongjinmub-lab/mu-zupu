# 2026-05-31 Webhook 单条投递手动重试增量验收

## 本轮目标

在 Webhook 自动重试 Worker 和投递记录筛选基础上，补充管理台手动排障能力：对单条失败投递记录立即重试。

本轮按用户要求只做本地开发和本地验证，暂不做服务器部署验证。

## 后端变更

- 新增 `POST /api/v1/webhook-deliveries/{delivery_id}/retry`。
- 接口权限为 `tenant admin`。
- `delivery_id` 必须是合法 UUID。
- 仅当前租户下的 `failed` 投递记录允许重试。
- 重试时复用原投递记录中的事件类型、请求体和绑定 Webhook 配置。
- 重试后更新原投递记录：
  - 投递状态。
  - HTTP 状态码。
  - 响应摘要。
  - 错误信息。
  - 耗时。
  - 重试次数。
  - 下一次自动重试时间。
- 新增错误区分：
  - 投递记录不存在。
  - 投递记录不可重试。
  - 投递 ID 非法。

## 前端变更

- Webhook 投递记录中，失败记录显示“立即重试”按钮。
- 点击后调用单条重试接口。
- 重试完成后按当前筛选条件刷新投递记录。
- 页面继续使用中文摘要和 toast 提示，不新增黑色 JSON 原文区域。
