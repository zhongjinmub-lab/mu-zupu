# 2026-05-31 生产冒烟检查公网入口增强增量验收

## 目标

补强生产 `smoke.sh`，避免只检查本机端口导致误判。冒烟检查以公网 Nginx 入口为准，同时覆盖前端静态资源、Nginx 配置、systemd 服务和迁移状态。

## 变更

- `smoke.sh` 新增 `API_BASE_URL`，默认 `https://zupu.jiangxinnet.com/saas-api/api/v1`。
- `smoke.sh` 新增 `FRONTEND_BASE_URL`，默认 `https://zupu.jiangxinnet.com/saas`。
- 新增公网 API 检查：
  - `/health`
  - `/ready`
- 新增前端静态资源检查：
  - `/saas/`
  - `/saas/assets/app.js`
  - `/saas/assets/app.css`
- 新增 `nginx -t` 检查，可通过 `CHECK_NGINX=no` 跳过。
- 保留 systemd 服务检查：
  - `mu-agent-saas`
  - `mu-agent-document-worker`
  - `mu-agent-webhook-worker`
- 保留迁移状态检查，并支持 `EXPECTED_MIGRATION` 覆盖。
- 输出改为逐项中文可读前缀 `OK/FAIL`，失败立即退出。
