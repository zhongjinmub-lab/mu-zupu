## 技术基线

- Go go1.26.3 + Gin
- PostgreSQL 16 + pgvector
- Redis 7.4
- MinIO / S3
- 当前交付管理台为免构建静态前端，源码位于 `02_frontend/index.html`、`02_frontend/assets/app.js`、`02_frontend/assets/app.css`
- Vue3 + TypeScript + Vite + Element Plus 为后续统一工程化迁移目标
- Docker Compose

## 使用建议

1. 查看 `06_交付验收清单.md` 确认功能、安全和运维验收状态；
2. 查看 `04_API接口清单.md` 确认接口路径、鉴权范围和响应摘要；
3. 查看 2026-05-31 系列增量验收文档确认 Webhook、SSE、限流、审计、敏感字段和运维脚本；
4. 部署前按 `../01_backend/deploy/production/README.md` 执行打包、升级、回滚和恢复演练。
