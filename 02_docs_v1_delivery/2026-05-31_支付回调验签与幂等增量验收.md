# 2026-05-31 支付回调验签与幂等增量验收

## 增量范围

- 新增 `PAYMENT_CALLBACK_SECRET` 环境变量，用于支付回调 HMAC-SHA256 验签。
- `POST /api/v1/payment-callbacks/:channel` 在配置密钥后强制校验 `X-Payment-Signature`。
- 签名原文为原始 JSON 请求体，签名格式为 `sha256=<hex>`。
- 未配置密钥时保留 mock 开发体验，便于本地演示和回归。
- 原有支付回调幂等逻辑继续复用：已支付支付单不会重复改写订单和订阅，回调事件持续写入审计表。

## 验收点

- [x] 配置为空时，支付回调可按原 mock 流程执行。
- [x] 配置 `PAYMENT_CALLBACK_SECRET` 后，缺少签名的回调返回中文错误。
- [x] 配置 `PAYMENT_CALLBACK_SECRET` 后，错误签名的回调返回中文错误。
- [x] 正确签名格式为 `X-Payment-Signature: sha256=<hex>`。
- [x] 签名失败时不会调用支付单状态更新。
- [x] 支付回调事件表继续记录成功和失败回调结果，支撑幂等审计。

## 配置说明

生产环境应通过服务器环境文件或密钥管理系统注入：

```text
PAYMENT_CALLBACK_SECRET=请替换为生产密钥
```

真实密钥不得提交到代码仓库、前端静态资源或交付文档。
