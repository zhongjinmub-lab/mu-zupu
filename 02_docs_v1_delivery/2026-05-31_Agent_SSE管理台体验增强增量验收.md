# 2026-05-31 Agent SSE 管理台体验增强增量验收

## 本轮目标

在已有 Agent SSE 流式接口基础上，补齐管理台多轮会话的流式发送入口和中文结果摘要，让接口能力在静态管理台中可直接验证。

本轮只做本地主线开发，不执行服务器部署验证，不读取服务器信息文件。

## 前端变更

- 多轮会话表单新增“流式发送”按钮。
- 修复 JS 已绑定 `streamConversationBtn` 但页面缺少对应按钮的问题，避免管理台初始化事件绑定中断。
- 流式发送期间按钮会临时禁用，并显示“流式发送中”。
- 流式结果区改为结构化中文展示：
  - 流式回答内容。
  - 当前状态。
  - 引用资料。
  - 完成后的会话、知识库、历史条数、模型、来源、引用数量和耗时。
- SSE `error` 事件继续保留已输出内容，并显示中文错误摘要。
- 对结束时仍留在缓冲区中的 SSE 内容做兜底解析，降低边界情况下最后一段未显示的风险。

## 后端变更

- 本轮未改变 SSE 后端协议。
- `start`、`reference`、`delta`、`done`、`error` 事件类型保持兼容。

## 验收要点

- 打开管理台 Agent 页面，多轮会话表单应同时存在“发送”“流式发送”“新会话”三个操作。
- 点击“流式发送”后按钮进入禁用状态，完成或失败后恢复。
- 流式回答会逐段追加显示。
- 完成后结果区显示中文元信息摘要，不显示黑色 JSON 原文区域。
- 流式失败时保留已输出内容，并显示中文错误摘要。
