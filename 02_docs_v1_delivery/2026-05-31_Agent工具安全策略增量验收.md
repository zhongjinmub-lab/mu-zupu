# 2026-05-31 Agent 工具安全策略增量验收

## 增量范围

- 新增 `GET /api/v1/agents/tool-safety-policy`，返回 Agent 工具安全策略摘要。
- 首版默认 `enabled=false`、`default_action=deny`，模型不能自主调用外部工具。
- 计划中的只读工具：知识库检索、文件资料查询。
- 危险工具：知识库写入、账单授权操作，默认阻断，后续启用前必须人工确认。
- 策略声明后续真实工具执行必须校验租户权限并写入 `agent.tool.call` 审计动作。
- 管理台智能体页新增“Agent 工具安全策略”，用中文摘要展示工具状态、危险确认和审计要求。

## 验收点

- [x] 接口固定使用当前 `X-Tenant-ID` 租户上下文。
- [x] 默认策略拒绝工具调用，避免模型直接执行危险动作。
- [x] 危险工具标记为 `blocked` 且 `requires_confirmation=true`。
- [x] 策略明确后续工具调用必须校验 `tenant writer/admin` 权限。
- [x] 策略明确后续工具调用必须写入审计日志。
- [x] 管理台不展示黑色 JSON 原文，只展示中文摘要。

## 说明

本轮先固化工具安全边界和验收入口，不开放真实工具执行。后续接入真实 Tool Runtime 时，应在该策略基础上补充工具注册表、调用日志表、人工确认队列和执行器。
