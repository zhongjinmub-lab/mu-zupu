# 2026-05-28 KB 文档列表增量验收

## 变更范围

- 新增后端接口：`GET /api/v1/kbs/:kb_id/documents`。
- 管理台知识库页新增“文档列表”面板。
- 本次后端变更不需要 migration。

## 接口能力

`GET /api/v1/kbs/:kb_id/documents`

要求：

- `Authorization: Bearer <token>`
- `X-Tenant-ID: <tenant_id>`

查询参数：

| 参数 | 说明 |
|---|---|
| `limit` | 返回数量，默认 50，最大 200 |

返回：

```json
{
  "items": [
    {
      "id": "uuid",
      "tenant_id": "uuid",
      "knowledge_base_id": "uuid",
      "title": "文档标题",
      "source_type": "file",
      "parse_status": "success",
      "chunk_status": "success",
      "embedding_status": "pending"
    }
  ]
}
```

## 隔离与安全

- 后端调用 `EnsureAccess` 校验当前 `tenant_id + kb_id`。
- 查询固定在当前租户和当前知识库内。
- 不接受客户端覆盖 `tenant_id`。

## 线上验证

管理台入口：

```text
https://zupu.jiangxinnet.com/saas/
```

已验证页面包含：

- `文档列表`
- `documentListFilterForm`
- `loadDocumentsBtn`

真实 API 回归：

- 新建租户与 KB。
- 调用文档列表，初始 `before_count=0`。
- 上传 `.txt` 文件。
- 创建并执行 `parse_chunk` 文档任务。
- 再次调用文档列表，`after_count=1`。
- 返回文档状态：
  - `source_type=file`
  - `chunk_status=success`
  - `embedding_status=pending`
