# 2026-05-29 文件下载增量验收

## 后端接口

- `GET /api/v1/files/:file_id/download`
  - 下载当前租户下已上传文件对象；
  - 响应为二进制流；
  - 设置 `Content-Type`、`Content-Length` 和 `Content-Disposition`。

## 隔离约束

- 接口要求 `Authorization: Bearer <token>` 和 `X-Tenant-ID: <tenant_id>`；
- Repository 查询固定携带 `tenant_id + file_id`；
- 文件对象只从该文件记录的 `object_key` 读取；
- 跨租户或不存在的文件返回 404；
- 本次只新增只读下载接口，无数据库结构变更，无新增 migration。

## 管理台

- 文件列表每条记录新增“下载”操作；
- 前端使用 `fetch` 携带 JWT 与 `X-Tenant-ID`，收到 Blob 后触发浏览器下载。
