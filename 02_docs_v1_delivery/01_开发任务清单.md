# 智能体族谱SAAS v1.0 开发任务清单

## 1. P0 必做任务

| 编号 | 任务 | 验收目标 |
|---|---|---|
| T01 | 基础工程 | 本地启动、配置、日志、响应、健康检查、迁移可用 |
| T02 | 租户权限 | 租户、成员、角色、权限、审计、多租户隔离可用 |
| T03 | 套餐计费 | 套餐、订阅、额度、用量限制生效 |
| T04 | Agent Runtime | 智能体创建、版本、会话、执行记录可用 |
| T05 | RAG 知识库 | 上传、解析、切片、embedding、检索、引用溯源跑通 |
| T06 | 三套后台 | 开发商、服务商、客户后台按角色隔离 |
| T07 | 支付订单 | 业务订单、支付订单、回调幂等、主动查单可用 |
| T08 | License 授权 | 在线/离线授权、机器绑定、吊销、验签可用 |
| T09 | 安全审计 | 操作、登录、工具、支付、授权审计可查 |
| T10 | 部署交付 | Docker Compose、环境变量、备份、恢复、验收文档完整 |

## 2. P1 扩展任务

| 编号 | 任务 | 验收目标 |
|---|---|---|
| E01 | 插件与工具 | Tool Schema、插件启停、工具授权、调用日志可用 |
| E02 | MCP 网关 | Agent 可按权限调用 MCP 工具 |
| E03 | 工作流编排 | 条件、工具、LLM、人工确认节点可编排 |
| E04 | 多端渠道 | Web/H5/小程序/公众号等入口预留并可扩展 |
| E05 | 服务商运营 | 分销、客户、订单、工单、白标能力增强 |
