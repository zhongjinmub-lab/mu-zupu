# 智能体族谱SAAS MVP 一期开发排期

建议周期：8 周。MVP 目标是跑通 SaaS 管理、Agent、RAG、用量、授权和部署验收主链路。

## 1. 8 周计划

| 周期 | 主题 | 验收结果 |
|---|---|---|
| 第 1 周 | 工程底座 | 本地启动、健康检查、迁移、基础 API 可用 |
| 第 2 周 | 租户权限 | 登录、租户、成员、角色、权限、审计可用 |
| 第 3 周 | 套餐用量 | 套餐、订阅、额度、用量统计和限制生效 |
| 第 4 周 | Agent Runtime | Agent 创建、配置、版本、测试会话可用 |
| 第 5 周 | RAG 知识库 | 文件上传、解析、切片、向量化、检索跑通 |
| 第 6 周 | 插件工具 | 工具配置、授权、调用、审计可用 |
| 第 7 周 | 支付授权 | 模拟支付、订单开通、License 验签可用 |
| 第 8 周 | 部署验收 | 演示环境、监控、备份、交付验收完成 |

## 2. MVP 主链路

1. 创建租户和管理员；
2. 创建套餐并开通订阅；
3. 创建 Agent；
4. 创建知识库并上传文档；
5. 文档解析、切片、向量化；
6. Agent 基于知识库回答并展示引用来源；
7. Agent 调用工具并记录审计；
8. 产生命中用量和额度扣减；
9. 模拟支付完成续费或升级；
10. 生成并验证 License；
11. 查看日志、审计和监控；
12. 完成备份恢复验证。

## 3. 每周交付要求

- 代码合并到主分支或开发分支；
- SQL 迁移和回滚同步提交；
- API 文档同步更新；
- 核心接口测试通过；
- 每周至少演示一条可运行链路。
