# 2026-05-31 API 限流与审计闭环摘要增量验收

## 本轮目标

把已实现的 API 限流和审计能力整理成可查询、可展示、可验收的中文摘要，补齐安全验收项中的“API 限流和完整审计”。

## 后端增量

- 新增 `GET /settings/rate-limit-audit`。
- 返回当前限流策略、审计覆盖范围、自动审计动作、业务审计动作、审计查询能力和闭环说明。
- 摘要不返回 Redis 地址、Redis 密码、数据库编号或任何连接密钥。

## 已覆盖能力

- 登录和注册按 IP 限流。
- 租户级 API 按租户和用户双维度限流。
- Redis 限流异常时自动回退内存计数；内存限流可用于本地或单实例部署。
- 租户级 POST、PUT、PATCH、DELETE 写操作自动写入 `audit_logs`。
- 成员添加、角色调整、成员移除、邀请创建、邀请撤销、邀请接受等关键业务动作写入审计。
- 审计日志支持筛选、cursor 分页和 CSV 导出。

## 前端增量

- 设置页新增“限流与审计闭环摘要”。
- 用中文卡片展示租户/用户/IP 限流、自动审计动作、业务审计动作、查询导出能力和闭环说明。
- 不展示黑色 JSON 原文区域。

## 验收方式

- `GET /settings/rate-limit-audit` 返回统一响应结构。
- 响应中包含 `rate_limit`、`audit`、`automatic_actions`、`business_actions`、`query_capabilities`。
- 响应中不包含 Redis 地址或 Redis 密码。
- 管理台设置页刷新后展示中文摘要。
- `D:\Node.js\node.exe --check 02_frontend\assets\app.js` 通过。
- `go test ./...` 通过。
