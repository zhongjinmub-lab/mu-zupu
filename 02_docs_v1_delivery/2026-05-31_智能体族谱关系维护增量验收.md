# 智能体族谱关系维护增量验收

## 本轮目标

在已有智能体族谱只读图谱基础上，补齐最小可用的关系维护能力：新增父子关系、删除关系，并在管理台图谱区直接操作。

## 后端变更

- 新增 `POST /agent-genealogy/edges`。
- 新增 `DELETE /agent-genealogy/edges/{edge_id}`。
- 创建关系时校验当前租户、父子智能体、关系类型、重复关系和循环关系。
- 删除关系时固定按当前租户隔离，不能删除其他租户关系。
- 新增 `CreateGenealogyEdgeRequest` 归一化与校验测试。

## 前端变更

- 智能体页“智能体族谱图谱”区域新增关系维护表单。
- 支持选择父智能体、子智能体和关系类型新增关系。
- 关系列表新增“删除关系”按钮。
- 新增或删除后自动刷新图谱，并用中文提示结果。

## 验收步骤

1. 创建至少两个智能体。
2. 在“智能体族谱图谱”区域选择父智能体、子智能体和关系类型，点击“新增关系”。
3. 确认关系数量增加，关系列表显示父子节点和中文关系类型。
4. 尝试选择相同父子智能体，确认前端提示“父智能体和子智能体不能相同”。
5. 再次创建相同关系，确认后端返回重复关系错误。
6. 已有 `A → B` 时，尝试创建 `B → A`，确认后端返回“族谱关系会形成循环，请调整父子节点”。
7. 点击“删除关系”，确认关系列表和关系数量刷新。

## 注意事项

- 本轮不做拖拽式图谱编辑。
- 本轮不部署服务器，部署验证留到后续明确要求时执行。
- 本轮不读取服务器信息文件，不写入任何密钥。
