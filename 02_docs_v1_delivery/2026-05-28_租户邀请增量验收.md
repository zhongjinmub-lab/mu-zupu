# 2026-05-28 租户邀请增量验收

## 变更范围

- 新增 `000016_tenant_invitations` up/down migration。
- 新增 `tenant_invitations` 表。
- 邀请 token 只在创建响应中返回一次，数据库只保存 SHA-256 hash。
- 新增邀请创建、列表、撤销、接受接口。
- 接受邀请时校验 token、状态、过期时间和当前登录用户邮箱。
- 管理台 `/saas/` 新增租户邀请和接受邀请入口。

## 新增接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/tenant/invitations` | 当前租户创建邀请 |
| GET | `/api/v1/tenant/invitations` | 当前租户邀请列表 |
| POST | `/api/v1/tenant/invitations/:invitation_id/revoke` | 撤销当前租户邀请 |
| POST | `/api/v1/tenant-invitations/accept` | 当前登录用户接受邀请 |

## 权限规则

- 创建、列表、撤销邀请要求当前租户角色为 `owner` 或 `admin`。
- 接受邀请要求登录用户邮箱与邀请邮箱一致。
- 邀请角色只允许 `admin`、`member`、`viewer`，不允许邀请 `owner`。
