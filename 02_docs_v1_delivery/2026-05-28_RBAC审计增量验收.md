# 2026-05-28 RBAC 与审计增量验收

## 变更范围

- 新增 `000015_tenant_members_audit_rbac` up/down migration。
- 基于现有 `tenant_members.role_code` 增加 RBAC MVP 约束。
- 新增租户成员管理接口。
- 新增租户审计日志查询接口。
- 成员添加、角色修改、成员移除会写入 `audit_logs`。
- 管理台 `/saas/` 新增租户成员与审计日志入口。

## 新增接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/tenant/members` | 当前租户成员列表 |
| POST | `/api/v1/tenant/members` | 按邮箱添加当前租户成员 |
| PUT | `/api/v1/tenant/members/:member_id/role` | 修改当前租户成员角色 |
| DELETE | `/api/v1/tenant/members/:member_id` | 移除当前租户成员 |
| GET | `/api/v1/audit-logs` | 当前租户审计日志列表，支持 `action` 过滤 |

## 权限规则

- `owner` 和 `admin` 可管理租户成员。
- `member` 和 `viewer` 不能管理租户成员。
- `owner` 成员不能被移除。
- 成员查询、修改、删除均按当前 `tenant_id` 隔离。
