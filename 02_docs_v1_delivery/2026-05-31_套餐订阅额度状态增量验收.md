# 2026-05-31 套餐订阅额度状态增量验收

## 增量范围

- 新增 `GET /api/v1/billing/quota/status`，返回当前租户 active 订阅下的额度状态。
- 覆盖指标：RAG 问答请求、Agent 会话消息、文件上传容量、知识切片向量化。
- 返回字段包含套餐编码、指标、中文名称、上限、已用、剩余、是否限制、是否允许继续使用和单位。
- 管理台“用量与订单”页面新增“套餐额度状态”面板，使用中文摘要卡片展示，不新增黑色 JSON 原文区域。

## 验收点

- [x] 无订阅租户访问额度状态时会沿用现有逻辑自动创建 `free` 订阅。
- [x] 已用量按当前租户和当前订阅周期统计。
- [x] 额度不足时接口返回 `allowed=false`，执行类接口仍通过现有 `EnsureQuota` 返回 `402 quota exceeded`。
- [x] 文件上传、向量化、RAG 问答、Agent 会话均已有执行前额度拦截。
- [x] 管理台可直接查看已用、上限、剩余和使用率。

## 说明

本轮不调整套餐模型和计费迁移，只补齐额度状态查询与管理台可视化，便于验收“套餐、订阅、额度限制生效”。
