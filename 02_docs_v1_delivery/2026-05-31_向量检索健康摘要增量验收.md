# 2026-05-31 向量检索健康摘要增量验收

## 目标

补齐 RAG 向量检索链路的可观测摘要入口，便于在不暴露数据库连接串、模型 Key 和原始向量的前提下，从管理台确认 pgvector/HNSW、1536 维 embedding、租户隔离、知识库隔离、检索日志和运维检查状态。

## 后端

- 新增 `GET /api/v1/settings/vector-search`。
- 返回统一响应结构，`data` 包含：
  - `status`
  - `embedding_provider`
  - `embedding_model`
  - `embedding_dimension`
  - `index_profile`
  - `isolation_checks`
  - `retrieval_checks`
  - `operations_checks`
  - `operational_notes`
- 接口不返回数据库 DSN、Embedding API Key、原始向量内容或检索请求原文。

## 前端

- 设置页新增“向量检索健康摘要”。
- 使用中文卡片展示：
  - 检索状态；
  - 向量维度；
  - pgvector/HNSW 索引配置；
  - 向量与全文召回权重；
  - 租户隔离、知识库隔离、删除态过滤；
  - 向量维度、混合检索、检索日志；
  - 索引迁移、批量导入维护、慢查询观察。
- 不新增黑色 JSON 原文区域。
