# 2026-05-31 Agent 工具目录与安全测试增量验收

## 增量范围

- 新增 `GET /api/v1/tools`，返回当前租户可见的 Agent 工具目录。
- 新增 `POST /api/v1/tools/{id}/test`，返回工具 dry-run 安全测试结果。
- 只读工具当前返回“测试通过安全预检”，不执行真实外部查询。
- 危险工具当前返回“已被安全策略阻断”，不执行知识库写入、支付、授权或 Webhook 操作。
- 管理台 Agent 工具安全策略区展示工具目录、安全测试按钮和中文测试摘要。

## 验收点

- [x] 工具目录固定使用当前 `X-Tenant-ID` 租户上下文。
- [x] `/tools` 返回工具状态、权限要求、确认要求、审计动作和运维说明。
- [x] `/tools/{id}/test` 对只读工具只做 dry-run，不访问外部系统。
- [x] `/tools/{id}/test` 对危险工具返回阻断摘要。
- [x] 管理台不展示黑色 JSON 原文，只展示中文卡片摘要。
- [x] 后端单测覆盖工具目录、缺失工具、只读 dry-run 和危险工具阻断。

- 后端：`go test ./...`
- 前端：`D:\Node.js\node.exe --check 02_frontend\assets\app.js`
- 交付：`powershell -NoProfile -ExecutionPolicy Bypass -File .\verify_delivery.ps1`
