# 智能体族谱统计分析增量验收

## 本轮目标

在已有智能体族谱图谱、关系维护和 CSV 导出能力基础上，把族谱结构统计接入数据分析面板，让总后台可以直接查看当前租户的智能体关系健康度。

## 后端变更

- 扩展 `GET /analytics/summary` 响应，新增 `genealogy` 字段。
- 新增统计项：
  - `nodes`：当前租户未归档智能体数量。
  - `edges`：当前租户有效族谱关系数量。
  - `roots`：没有有效父节点关系的未归档智能体数量。
  - `isolated`：既没有有效父节点关系，也没有有效子节点关系的未归档智能体数量。
  - `relation_types`：按关系类型聚合的数量。
- 统计口径与图谱接口保持一致：只统计当前租户数据，并过滤已归档智能体。

## 前端变更

- 管理台“数据分析面板”新增“智能体族谱结构”区域。
- 展示节点、关系、根节点和孤立节点四个摘要指标。
- 展示派生、继承、组合、路由等关系类型分布。
- 所有结果使用中文摘要展示，不新增黑色 JSON 原文展示区。

## 验收步骤

1. 登录管理台并选择租户。
2. 打开“智能体”页面，创建或确认存在若干智能体族谱关系。
3. 打开“数据分析面板”，点击“刷新分析”。
4. 确认“智能体族谱结构”区域展示节点、关系、根节点、孤立节点。
5. 确认关系类型分布显示为“派生、继承、组合、路由”等中文标签。
6. 归档某个智能体后再次刷新，确认统计不再计入已归档智能体。

- 后端测试：在 `01_backend` 目录执行 `go test ./...`
- 差异检查：`git diff --check`

## 注意事项

- 本轮不新增数据库迁移。
- 本轮不部署服务器，部署验证留到后续明确要求时执行。
- 本轮不读取服务器信息文件，不写入任何密钥。
