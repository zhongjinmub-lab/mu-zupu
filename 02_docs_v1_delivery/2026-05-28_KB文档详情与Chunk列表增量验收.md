# 2026-05-28 KB 文档详情与 Chunk 列表增量验收

## 后端接口

- `GET /api/v1/kbs/:kb_id/documents/:document_id`
  - 返回当前租户当前 KB 下单个文档详情；
  - 响应 `data.document` 为文档对象，`data.file_id` 为关联文件 ID，非文件文档为空字符串。
- `GET /api/v1/kbs/:kb_id/documents/:document_id/chunks`
  - 返回当前租户当前 KB 下单个文档 chunks；
  - 按 `chunk_no ASC, created_at ASC` 排序；
  - `limit` 默认 100，最大 500。

## 隔离约束

- 两个接口均要求 `Authorization: Bearer <token>` 和 `X-Tenant-ID: <tenant_id>`；
- Repository 查询固定携带 `tenant_id + kb_id + document_id`；
- 跨租户、跨 KB 或不存在的文档返回 404；
- 本次只新增只读接口，无数据库结构变更，无新增 migration。

## 管理台

- 文档列表每条记录新增“查看详情”和“查看 Chunk”操作；
- 详情区展示后端返回的 document/file_id；
- Chunk 区展示 chunk 序号、embedding 状态、token 数、embedding model 和正文。
