# 2026-05-29 Agent 知识库绑定管理台增量验收

## 管理台

- 智能体页新增“知识库绑定”区域；
- 支持选择 Agent 与当前租户知识库后调用 `POST /api/v1/agents/:agent_id/knowledge-bases` 绑定；
- 支持刷新并查看 `GET /api/v1/agents/:agent_id/knowledge-bases` 已绑定知识库列表；
- 支持对已绑定知识库调用 `DELETE /api/v1/agents/:agent_id/knowledge-bases/:kb_id` 解绑；
- 绑定关系刷新后可继续配合测试会话和多轮会话使用默认绑定知识库。

## 隔离约束

- 所有请求继续携带 `Authorization: Bearer <token>` 和 `X-Tenant-ID: <tenant_id>`；
- 绑定前复用后端已落地的当前租户 KB 访问校验；
- 解绑固定按 `tenant_id + agent_id + kb_id` 软删除；
- 本增量不新增数据库结构，不新增后端接口。
