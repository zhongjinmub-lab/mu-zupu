# 智能体族谱图谱只读接口增量验收

## 本轮目标

补齐“智能体族谱”主线的最小可视化闭环：新增族谱关系表、只读图谱接口，并在静态管理台展示当前租户的智能体节点和关系。

## 后端变更

- 新增迁移 `000020_agent_genealogy`。
- 新增 `agent_genealogy` 表，支持父子智能体关系。
- 新增 `GET /agent-genealogy/graph`。
- 接口返回当前租户未归档智能体节点，以及当前租户下的族谱关系。
- 首版关系类型支持 `fork`、`inherit`、`compose`、`route`。

## 前端变更

- 管理台智能体页新增“智能体族谱图谱”区域。
- 展示节点数量、关系数量、根节点数量。
- 使用节点卡片展示智能体名称、编码、状态、上游数量和下游数量。
- 使用关系列表展示父节点、子节点、关系类型和创建时间。
- 展示均为中文摘要，不新增黑色 JSON 原文区域。

## 验收步骤

1. 应用数据库迁移，确认 `agent_genealogy` 表存在。
2. 登录管理台并选择租户。
3. 打开“智能体”页面，确认“智能体族谱图谱”区域可见。
4. 点击“刷新”，确认节点数量和智能体列表一致。
5. 在数据库插入一条当前租户下的族谱关系后刷新，确认关系列表展示父子关系。
6. 切换租户后刷新，确认只显示当前租户数据。

## 验证命令

- 前端语法检查：`D:\Node.js\node.exe --check 02_frontend\assets\app.js`
- 后端测试：在 `01_backend` 目录执行 `go test ./...`
- 差异检查：`git diff --check`

## 注意事项

- 本轮只做只读展示，不提供关系创建、编辑、删除入口。
- 本轮不部署服务器，部署验证留到后续明确要求时执行。
- 本轮不读取服务器信息文件，不写入任何密钥。
