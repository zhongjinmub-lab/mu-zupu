# 2026-05-31 角色权限矩阵增量验收

## 增量范围

- 新增 `GET /api/v1/tenant/role-permissions`，返回当前租户固定角色权限矩阵。
- 角色范围：`owner`、`admin`、`member`、`viewer`。
- 返回当前用户在租户内的 `current_role`，以及每个角色的中文名称、权限范围、可读/可写/可管理能力、权限清单和受限操作。
- 管理台总览新增“角色权限矩阵”，用中文摘要展示角色能力，不新增黑色 JSON 原文区域。

## 验收点

- [x] 接口固定使用当前 `X-Tenant-ID` 租户上下文，不接受客户端覆盖租户。
- [x] `owner/admin` 可管理成员、账单授权和外部集成。
- [x] `member` 可维护知识库、文件和智能体，但不能管理成员、订单、License、Webhook 或支付回调。
- [x] `viewer` 仅可查看，不能执行写入和危险操作。
- [x] 成员添加、角色调整、成员移除继续写入审计日志。
- [x] 管理台可直接看到当前角色和各角色限制。

## 说明

本轮不引入动态 RBAC 表，继续沿用当前 SaaS 固定角色模型，避免迁移和权限重构扩大风险。后续如需企业级自定义角色，可在该摘要接口基础上替换为数据库驱动权限策略。
