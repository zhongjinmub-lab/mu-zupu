# 智能体族谱结构诊断摘要增量验收

## 本轮目标

在已有智能体族谱图谱、筛选和 CSV 导出能力基础上，把图谱结构诊断摘要下沉到后端统一计算，方便管理台直接展示当前筛选结果下的结构健康度。

## 后端变更

- `GET /agent-genealogy/graph` 响应新增 `summary` 字段。
- `summary` 包含：
  - `nodes`：当前图谱节点数。
  - `edges`：当前图谱关系数。
  - `roots`：没有有效父节点关系的节点数。
  - `isolated`：既没有有效入边，也没有有效出边的孤立节点数。
  - `relation_types`：按关系类型聚合的数量。
- 诊断摘要复用当前 `q` 和 `relation_type` 筛选结果。
- 新增结构摘要计算单元测试，覆盖普通父子关系和根节点标记关系。

## 前端变更

- 管理台“智能体族谱图谱”摘要区改为优先使用后端 `summary`。
- 新增展示“孤立节点”和“关系类型分布”。
- 筛选状态继续以中文摘要展示。
- 不新增黑色 JSON 原文展示区。

## 验收步骤

1. 登录管理台并选择租户。
2. 打开“智能体”页面。
3. 确认“智能体族谱图谱”摘要区展示节点、关系、根节点、孤立节点和关系类型分布。
4. 输入关键词或选择关系类型后点击“筛选”。
5. 确认摘要指标随筛选结果同步变化。
6. 若存在没有任何关系的智能体，确认其计入孤立节点。
