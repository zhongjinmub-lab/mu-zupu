# 2026-05-31 敏感字段保护摘要增量验收

## 本轮目标

补齐“敏感字段加密存储并脱敏展示”的可验收入口，让管理台能用中文摘要确认密钥隔离、哈希存储和响应脱敏状态，不展示黑色 JSON 原文区域。

## 后端增量

- 新增 `GET /settings/sensitive-fields`。
- 返回 `environment_secrets`、`stored_secrets`、`response_redactions` 和 `operational_notes` 四类摘要。
- 接口只返回是否配置、保护方式和 API 暴露策略，不返回真实密钥、Token、数据库 DSN、Redis 密码、对象存储密钥、模型 API Key、Webhook secret 或 License signature。
- 覆盖范围包括 JWT、数据库连接串、对象存储、模型服务 API Key、支付回调验签密钥、用户密码哈希、租户邀请 token_hash、Webhook 签名密钥和 License 离线签名。

## 前端增量

- 设置页新增“敏感字段保护摘要”区块。
- 用中文卡片展示环境变量隔离、存储保护、响应脱敏和运维说明。
- 租户邀请 Token 创建结果改为中文一次性提示，不再使用黑色代码块展示。

## 验收方式

- `GET /settings/sensitive-fields` 返回统一响应结构。
- 响应中不包含 `postgres://`、真实密钥、API Key 或密码原文。
- 管理台设置页刷新后展示中文摘要。
- `D:\Node.js\node.exe --check 02_frontend\assets\app.js` 通过。
- `go test ./...` 通过。
