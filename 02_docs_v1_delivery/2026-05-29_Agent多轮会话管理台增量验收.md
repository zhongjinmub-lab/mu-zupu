# 2026-05-29 Agent 多轮会话管理台增量验收

## 管理台

- 智能体页新增“多轮会话”区域；
- 支持选择 Agent 与可选知识库后调用 `POST /api/v1/agents/:agent_id/chat` 发送多轮消息；
- 支持保留当前 `conversation_id` 续聊，也支持“新会话”清空当前会话上下文；
- 支持刷新并查看 `GET /api/v1/agents/:agent_id/conversations` 会话列表；
- 支持点击会话后查看 `GET /api/v1/agents/:agent_id/conversations/:conversation_id/messages` 消息列表；
- 发送成功后刷新会话列表、消息列表和用量汇总，并展示 `history_used`。

## 隔离约束

- 所有请求继续携带 `Authorization: Bearer <token>` 和 `X-Tenant-ID: <tenant_id>`；
- 会话与消息查询复用后端已落地的 `tenant_id + agent_id + conversation_id` 隔离；
- 本增量不新增数据库结构，不新增后端接口。

- `go test ./...` 通过；
- 前端静态文件为免构建交付，已做 JavaScript 语法检查。
