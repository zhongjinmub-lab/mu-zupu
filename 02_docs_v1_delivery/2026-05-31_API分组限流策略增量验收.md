# 2026-05-31 API 分组限流策略增量验收

## 目标

在已有租户级、用户级和登录注册 IP 限流基础上，补充分组限流能力，优先覆盖高成本或容易误触发的接口：Webhook 测试发送和 Agent SSE 流式对话。

## 后端

- `RateLimiter` 新增 `TenantAndUserScoped`，限流 Key 增加 `scope`，避免不同接口分组互相挤占计数。
- 默认租户级业务 API 继续沿用原有租户/用户限流。
- `POST /api/v1/webhooks/{webhook_id}/test` 已挂载 `webhook_test` scope。
- `POST /api/v1/agents/{agent_id}/chat/stream` 已挂载 `agent_stream` scope。
- `/settings/rate-limit` 响应新增 `scoped_policies`，展示登录注册、默认租户 API、Webhook 测试发送和 Agent SSE 流式对话的策略摘要。

## 前端

- 设置页“API 限流策略”新增分组策略中文卡片。
- 展示每个分组的接口范围、Key 维度、窗口阈值和用途说明。
- 不新增黑色 JSON 原文区域。

## 验收

- [x] 默认限流和分组限流使用独立计数 Key。
- [x] Webhook 测试发送具备独立 scope。
- [x] Agent SSE 流式对话具备独立 scope。
- [x] 设置页可展示分组限流策略摘要。
- [x] API 文档已补充 `scoped_policies` 字段说明。
- [x] 本轮不部署服务器，部署验证留到后续明确要求时执行。
