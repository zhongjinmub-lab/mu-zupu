# 2026-05-28 通用审计中间件增量验收

## 变更范围

- 新增租户范围通用审计中间件 `tenant.AuditMiddleware`。
- 对租户上下文内的 `POST`、`PUT`、`PATCH`、`DELETE` 自动写入 `audit_logs`。
- 审计记录不保存请求 body，避免敏感信息进入日志。
- 审计 metadata 记录：
  - `method`
  - `path`
  - `route`
  - `status`
  - `request_id`
  - `role_code`

## 审计动作

| action | resource_type | 说明 |
|---|---|---|
| `http.post` | `http_request` | 租户范围 POST 请求 |
| `http.put` | `http_request` | 租户范围 PUT 请求 |
| `http.patch` | `http_request` | 租户范围 PATCH 请求 |
| `http.delete` | `http_request` | 租户范围 DELETE 请求 |
