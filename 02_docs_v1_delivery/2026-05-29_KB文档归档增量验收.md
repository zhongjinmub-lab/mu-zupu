# 2026-05-29 KB 文档归档增量验收

## 后端接口

- `DELETE /api/v1/kbs/:kb_id/documents/:document_id`
  - 归档当前租户当前 KB 下的文档；
  - 响应 `data.archived=true`。

## 隔离约束

- 接口要求 `Authorization: Bearer <token>` 和 `X-Tenant-ID: <tenant_id>`；
- Repository 更新固定携带 `tenant_id + kb_id + document_id`；
- 跨租户、跨 KB 或不存在的文档返回 404；
- 同事务软删除：
  - `documents.deleted_at`
  - 该文档的 `document_chunks.deleted_at`
  - 该文档关联 `document_jobs.deleted_at`
- 原始上传文件记录和对象存储文件不删除；
- 本次无数据库结构变更，无新增 migration。

## 管理台

- 文档列表每条记录新增“归档”操作；
- 归档后刷新文档列表、待向量化 Chunk 和文档任务列表；
- 当前选中文档详情与 Chunk 列表清空。
