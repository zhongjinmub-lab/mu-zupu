# 2026-05-31 License 在线/离线授权验证增量验收

## 增量范围

- `POST /api/v1/licenses/:license_id/verify` 返回授权验证摘要字段：`mode`、`status`、`public_key_id`、`has_signature`、`valid`、`message`。
- 普通 `tenant`、`trial` License 走在线状态校验，校验吊销状态和到期时间。
- `offline` 或带 `signature/public_key_id` 的 License 走 Ed25519 离线验签，使用服务端 `LICENSE_PUBLIC_KEYS` 中配置的公钥。
- 管理台 License 列表新增中文摘要：授权模式、签名状态、公钥标识、到期时间、最近验证结果。
- License 接口响应不返回签名原文，只返回 `has_signature` 供管理台展示签名状态。
- 验证结果只展示中文摘要，不新增黑色 JSON 原文区域。

## 验收点

- [x] 在线 License 不需要签名即可验证状态和到期时间。
- [x] 离线 License 缺少签名、公钥或公钥未配置时返回失败摘要。
- [x] 离线 License 签名正确时返回 `valid=true` 和 `mode=offline`。
- [x] 已吊销或已过期 License 验证失败。
- [x] 管理台点击“验证”后在列表内保留中文验证结果。
- [x] License 创建、激活、吊销仍按当前租户隔离。

## 配置说明

离线授权验签依赖服务端环境变量：

```text
LICENSE_PUBLIC_KEYS={"default":"base64-ed25519-public-key"}
```

交付包只记录配置格式，不包含 License 私钥或生产公钥原文。
