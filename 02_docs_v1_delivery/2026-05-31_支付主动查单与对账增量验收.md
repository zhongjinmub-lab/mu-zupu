# 2026-05-31 增量验收:支付主动查单与对账

## 背景

异步通知可能因网络等原因丢失,导致支付单状态停留在 pending。本次新增向第三方渠道主动查单的能力,作为对账兜底:查询渠道真实状态并在命中终态时同步入账。

## 后端

- [x] 新增可选接口 `payment.OrderQuerier`(`QueryOrder(ctx, payNo) (QueryResult, error)`),不破坏既有 `Provider` 接口;mock 渠道不实现,上层据此回退本地状态。
- [x] `AlipayProvider.QueryOrder`:调用 `alipay.trade.query`,对响应业务节点 `alipay_trade_query_response` 原文用支付宝公钥 RSA2 验签,映射 `trade_status`;`ACQ.TRADE_NOT_EXIST` 归类为未找到。
- [x] `WechatProvider.QueryOrder`:调用按商户订单号查单接口,应答带平台证书签名头时验签,映射 `trade_state`;HTTP 404 归类为未找到。
- [x] 新增 AES/JSON 辅助:`extractJSONObjectNode` 按原始字节精确截取业务节点(可跳过字符串内的花括号与转义)。
- [x] 支付宝渠道新增可注入 `HTTPClient` 以支持查单与离线单测。
- [x] `POST /payments/{payment_id}/query`:支付单非终态时主动查单,命中已支付/失败时复用 `ApplyPaymentCallback`(幂等、写审计事件、支付成功创建订阅并触发 `order.paid` Webhook);响应附带 `remote_status` 与 `reconciled`。
- [x] 抽取 `emitOrderPaid` 公共方法,创建支付、回调通知、查单对账三处复用。

## 前端

- [x] 管理台支付单「查单」提示展示渠道返回状态,并在发生对账更新时刷新支付单、订单、回调审计与订阅。
