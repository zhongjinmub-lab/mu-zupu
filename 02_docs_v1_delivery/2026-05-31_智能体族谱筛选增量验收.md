# 智能体族谱筛选增量验收

## 本轮目标

在已有智能体族谱图谱、关系维护和 CSV 导出基础上，补齐按关键词和关系类型排查族谱结构的能力，方便在智能体数量增多后快速定位关系。

## 后端变更

- `GET /agent-genealogy/graph` 新增筛选参数：
  - `q`：按智能体名称、编码或描述模糊匹配，最长 80 个字符。
  - `relation_type`：按关系类型筛选，支持 `fork`、`inherit`、`compose`、`route`。
- `GET /agent-genealogy/export` 同步支持上述筛选参数。
- 筛选固定按当前租户上下文执行，不接受客户端覆盖 `tenant_id`。
- 已归档智能体不会进入筛选结果；父节点已归档的关系不会进入结果。
- 增加 `GenealogyGraphQuery` normalize/validate 单元测试。

## 前端变更

- 管理台“智能体族谱图谱”区域新增筛选栏：
  - 关键词。
  - 关系类型。
  - 筛选。
  - 重置。
- 刷新图谱和 CSV 导出均复用当前筛选条件。
- 族谱维护表单的父/子智能体下拉继续使用完整智能体列表，不受筛选结果影响。
- 筛选状态在摘要区用中文展示，不新增黑色 JSON 原文区域。

## 验收步骤

1. 登录管理台并选择租户。
2. 打开“智能体”页面。
3. 在“智能体族谱图谱”区域输入关键词，点击“筛选”，确认节点和关系列表按关键词收敛。
4. 选择“关系类型”，点击“筛选”，确认只展示对应关系及相关节点。
5. 点击“导出 CSV”，确认导出文件复用当前筛选条件。
6. 点击“重置”，确认图谱恢复全部节点和关系。

- 本轮不部署服务器，部署验证留到后续明确要求时执行。
