# 向量存储与索引优化说明

## 1. 结论

MVP 使用 PostgreSQL 16 + pgvector 承载知识库向量检索。

| 项 | 配置 |
|---|---|
| 表 | document_chunks |
| 向量字段 | embedding vector(1536) |
| 索引 | HNSW + cosine |
| 检索 | 向量检索 / 混合检索 |
| 隔离 | tenant_id + knowledge_base_id |

## 2. 核心索引

```sql
CREATE INDEX idx_chunks_embedding_hnsw_cosine
ON document_chunks USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64)
WHERE embedding IS NOT NULL AND deleted_at IS NULL;
```

辅助索引：

```sql
CREATE INDEX idx_chunks_tenant_kb_doc
ON document_chunks(tenant_id, knowledge_base_id, document_id)
WHERE deleted_at IS NULL;

CREATE INDEX idx_chunks_search_vector_gin
ON document_chunks USING gin(search_vector);
```

## 3. 默认检索参数

| 参数 | 默认值 |
|---|---:|
| hnsw_ef_search | 80 |
| vector_weight | 0.7 |
| text_weight | 0.3 |
| top_k | 10 |
| candidate_k | 50 |
| min_score | 0.2 |

## 4. 检索链路

1. 校验请求和 embedding 维度；
2. 读取检索 Profile；
3. 设置 `hnsw.ef_search`；
4. 按租户和知识库过滤；
5. 召回候选 chunk；
6. 计算分数并过滤；
7. 返回结果；
8. 写入检索日志。

## 5. 混合检索公式

```text
score = vector_score * vector_weight + text_score * text_weight
```
