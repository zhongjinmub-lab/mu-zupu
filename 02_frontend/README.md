# 智能体族谱 SAAS 管理台源码说明

这是一个免构建的静态管理台，用于快速查看和操作已上线后端 API。当前交付包保留完整前端源码和静态资产，不依赖打包产物即可运行。

## 源码清单

| 路径 | 说明 |
|---|---|
| `index.html` | 管理台页面结构，包含总览、知识库、智能体、授权、用量与订单、分析、Webhook、设置等视图 |
| `assets/app.js` | 管理台业务逻辑、接口调用、状态管理、表单提交、SSE 流式会话、CSV 导出和中文摘要渲染 |
| `assets/app.css` | 管理台布局、响应式样式、卡片、表格、筛选栏、图谱节点和状态组件样式 |
| `ui-*.png` | 总后台布局参考图和移动端/桌面端验收截图 |
| `dist-frontend-*.tar.gz` | 历史增量静态包留档，用于追踪阶段性交付状态 |

## 本地预览

直接用浏览器打开 `index.html` 即可。

默认 API 地址：

```text
当前域名 + /saas-api/api/v1
```

本地打开时可在“连接”页把 API Base 改为：

```text
https://zupu.jiangxinnet.com/saas-api/api/v1
```

## 已覆盖

- 登录/注册；
- 租户列表和快速创建；
- 知识库创建、列表、文件上传、文件下载、文档列表、文档详情、文档归档、Chunk 列表和 RAG 问答；
- 智能体创建/编辑、发布/回滚、归档、知识库绑定、测试会话、多轮会话和 SSE 流式发送；
- 智能体族谱图谱、关系维护、环路校验、筛选、结构诊断摘要和 CSV 导出；
- License 创建、列表、激活、吊销；
- 套餐、当前订阅、用量汇总、业务订单、支付单和支付回调审计；
- 成员、邀请、审计日志筛选分页和审计日志 CSV 导出；
- Webhook 配置、编辑、测试发送、投递记录筛选、状态摘要、手动重试和 CSV 导出；
- 数据分析面板，读取 `/analytics/summary` 展示资源结构、经营分布、智能体族谱结构、近 7 天用量、最近操作和风险项，并支持分析摘要 CSV 导出；
- 设置页 API 连接、限流策略、运行配置摘要和运行监控摘要；
- 健康检查、就绪检查、总后台参考图风格布局、排行表、产品动态、待办、经营和系统洞察。

## 验证命令

前端源码语法检查：

```text
D:\Node.js\node.exe --check 02_frontend\assets\app.js
```

静态页面无需构建，部署前确认以下文件存在：

```text
02_frontend\index.html
02_frontend\assets\app.js
02_frontend\assets\app.css
```

## 部署

把 `02_frontend/` 目录作为静态站点根目录，或复制到 Nginx 站点目录，并让 `/saas-api/` 继续反向代理到后端服务。
