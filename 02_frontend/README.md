# 智能体族谱 SAAS 管理台 MVP

这是一个免构建的静态管理台，用于快速查看和操作已上线后端 API。

## 本地预览

直接用浏览器打开 `index.html` 即可。

默认 API 地址：

```text
当前域名 + /saas-api/api/v1
```

本地打开时可在“连接”页把 API Base 改为：

```text
https://zupu.jiangxinnet.com/saas-api/api/v1
```

## 已覆盖

- 登录/注册；
- 租户列表和快速创建；
- 知识库创建、列表、RAG 问答；
- 智能体创建/编辑、发布/回滚、归档、知识库绑定、测试会话和多轮会话；
- License 创建、列表、激活、吊销；
- 当前订阅和用量汇总；
- 健康检查。
- 总后台参考图风格布局，覆盖顶部导航、总览数据区和右侧信息栏。
- 总后台排行表和右侧产品动态/更新日志。
- 总后台真实数据总览，右侧服务、待办、经营、动态和系统洞察均由已加载系统状态派生。
- 数据分析面板，读取 `/analytics/summary` 展示资源结构、经营分布、近 7 天用量、最近操作和风险项。
- 审计日志支持按当前筛选条件导出 CSV。

## 部署

把 `02_frontend/` 目录作为静态站点根目录，或复制到 Nginx 站点目录，并让 `/saas-api/` 继续反向代理到后端服务。
